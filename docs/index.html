Macro Microcontroller 2

Homepage Downloads Guides Web Editor View Repository

Macro Microcontroller 2, an RP2040 microcontroller development board with an integrated macropad that lets you control GPIOs with keyboard keys on a single PCB, plus a custom BASIC interpreter and disk operating system.

Hardware Specifications

Dimensions: 96.52 × 35.56 mm
Microcontroller: RP2040
Flash Memory: 16MB
Power: 3.3V
